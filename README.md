## Actividad 5: Juego Memory ##

# Contenido #
Este repositorio cuenta con el juego memory de la libreria de python **freegames** copiado usando el comando "freegames copy memory"

Se realizó:
- Contar y desplegar el numero de taps
- Detectar cuando todos los cuadros se han destapado
- Centrar el dígito en el cuadro
- Usar emojis en lugar de digitos


# Objetivo #
Realizar 4 cambios y utilizar las herramientas de **github** y **git** como forks y pull requests

# Requisitos #
- Python 3.x
- Librería [`freegames`](https://pypi.org/project/freegames/)
